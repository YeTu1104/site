💡 提示： 本系统为原生零依赖网页，只需将文件解压并直接双击 index.html 即可在任意浏览器中完美运行。

一、项目文件存放结构

我的作品集文件夹/
├── index.html         (主网页结构)
├── styles.css         (复古像素样式)
├── works.js           (作品清单与调试配置，只需改它)
├── bg.png             (背景图 2048x1152 或 16:9 比例)
└── images/            (放置缩略图与高清图)
    ├── live2d/
    ├── standalone/
    └── ...

二、如何添加或修改作品 (works.js)

打开 works.js，修改对应的分类数组。例如新增一个 LIVE2D 作品：

const WORKS = {
  "LIVE2D": [
    {
      title: "我的新LIVE2D模型",
      thumb: "images/01_thumb.jpg",
      full: "images/01_video.mp4"  // 支持 .jpg, .png, .gif, .mp4 格式
    }
  ]
};

三、开启 DEBUG 模式微调热区与坐标

在 works.js 顶部将 DEBUG = true;，页面会显示红色测试边框和实时鼠标百分比坐标，方便在换用不同背景图时微调按钮与画布位置。
