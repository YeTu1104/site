**Description**: 90s Retro Mac/Windows Graphics Editor Style Pixel Portfolio Web App with Custom Scrollbar, Percentage Hotspots, Lightbox & Source Code Exporter.

**Files**:
- index.html: Main HTML layout containing the fixed 16:9 retro window container, left category buttons, canvas display area, custom vertical scrollbar, lightbox overlay, and code export/guide modal.
- styles.css: Retro pixel styles, pixelated borders, dither patterns, 16:9 responsive auto-scaling, button active inset shadows, lightbox animations, and debug overlay styles.
- works.js: Works configuration dataset, category dictionary with pre-populated sample works, debug toggle (`DEBUG = true/false`), and Chinese editing documentation comments.
- app.js: Logic module handling category selection, canvas rendering, custom scrollbar math (drag, wheel, arrow clicks, touch), lightbox media viewer, DEBUG coordinate overlay, and source code generator/downloader.
